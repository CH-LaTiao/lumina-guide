# 安全与隐私

## 安全

- 项目是研究原型，不是医疗器械或自动驾驶系统。
- 默认 `movement_allowed=false`；物理振动和移动授权必须通过硬件和场地验收。
- 地面线只改变地面拟合，不隐藏障碍。
- 过期相机、断线、共享内存停流或决策停滞时，系统必须撤回旧方向。
- 不得把云端回答直接当作安全通行许可。

## 隐私

- 本地感知和 Piper 语音不需要上传图像。
- 在线问答和自动求助必须单独授权，且只上传当前快照。
- 运行数据库、日志、模型、API Key、设备序列号和原始图像不进入 Git。
- 如果公开演示，必须使用合成图、脱敏图或明确获得同意的现场图。
