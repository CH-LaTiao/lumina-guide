# Security Policy

[简体中文](SECURITY.zh-CN.md) | [繁體中文](SECURITY.zh-TW.md) | [English](SECURITY.en.md)

Do not include any of the following in issues, pull requests, test data or commits:

- API keys, access tokens or passwords;
- Orbbec device serial numbers;
- user camera images or personal identifiers;
- internal databases, runtime logs or release archives.

Report security issues privately to **wzr0411@gmail.com**. Do not disclose exploitable details in a public issue.
